# Governance

The maintainers are responsible for release approval, scientific validation,
compatibility policy, issue triage, and security updates.

Compatibility behavior is versioned against the pinned MATLAB implementation.
Strict behavior may evolve only through reviewed, tested, and documented
changes. A stable release requires the gates in `VALIDATION.md`.

Issues are triaged by:

1. scientific correctness or data-integrity risk;
2. compatibility regression;
3. reproducibility, packaging, or security failure;
4. supported usability problem; and
5. proposed scope expansion.

Every release receives a versioned tag and changelog entry. New maintainers may
be added after sustained, reviewed contributions and explicit approval by the
existing maintainers.
