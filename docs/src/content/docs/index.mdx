## What EpiReSIM does

EpiReSIM creates simulated **case-control genotype datasets** for evaluating
methods that search for interactions among SNPs. It first constructs a
penetrance table for an epistatic model without marginal effects, then generates
new samples by recombining short fragments from control individuals in a
reference dataset.

scientific workflow.
:::

## Where this documentation came from

The original repository's usage manual consisted of one sentence instructing
users to run `EpiReSIM.m`. This manual preserves the original program's scope
and behavior while making the published method, the translated Python
interface, the input contract, and the validation limitations explicit.

The rewrite visibly credits the original authors and paper throughout, follows
the repository's [Rewrite.bio commitments](/EpiReSIM_conversion/project/rewrite-policy/), and keeps
compatibility claims tied to recorded evidence.
